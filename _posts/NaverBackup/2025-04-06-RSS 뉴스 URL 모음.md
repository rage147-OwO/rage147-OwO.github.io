SSH 프로토콜로 Git 리포지토리에 직접 푸시하려면, **git push** 명령어를 실행할 때 Git 리포지토리 URL의 프로토콜을 **ssh**로 설정해주어야 합니다. 예를 들어, 리포지토리 URL이 **https://github.com/username/repository.git**일 경우, **git@github.com:username/repository.git**으로 변경해주면 됩니다.

따라서, 다음과 같이 리포지토리 URL을 SSH 프로토콜로 변경하면 됩니다.

kotlin

git remote set-url origin git@github.com:username/repository.git

그리고 나서, **git push** 명령어를 실행하면 SSH 프로토콜로 Git 리포지토리에 직접 푸시할 수 있습니다.
