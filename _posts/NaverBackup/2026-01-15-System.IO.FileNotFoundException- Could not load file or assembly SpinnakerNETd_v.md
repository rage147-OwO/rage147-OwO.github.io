```
System.IO.FileNotFoundException: Could not load file or assembly 
'C:\sample\SpinnakerNETd_v140.dll'
```

C# 빌드를 하다 보면, DLL을 참조하는 경우가 있다.

필자의 Case는 SpinnakerNETd\_v140.dll 을 사용하다가 에러가 났는데, 실제 DLL위치가 존재함에도 에러가 나더라.

이런 경우는 아래 중 하나이다.

- DLL 파일 자체가 없음
- DLL은 있지만 **의존 DLL**을 찾지 못함
- x64 / x86 아키텍처 불일치
- Visual C++ 런타임 미설치
- Spinnaker SDK 런타임 경로가 PATH에 없음

본인의 Case는 2번으로, SpinnakerNETd\_v140.dll 이 내부적으로 다른 dll을 의존하더라. 그 이유로는

SpinnakerNETd\_v140.dll 에서 d의 의미가 debug용으로, 다른 Spinnaker SDK를 필요로 하더라. 그래서 d가 붙어있지 않은 SpinnakerNET\_v140.dll 일반 버전으로 교체했다.

참고로 SpinnakerNETd\_v140 에서 v140은 Visual Studio 2015 C++ 빌드 도구를 필요로 한다. 다음엔 이름을 잘 보자.
